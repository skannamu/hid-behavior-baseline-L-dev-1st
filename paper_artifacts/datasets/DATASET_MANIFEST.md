# Dataset Manifest

The full dataset files are not included in this GitHub repository due to GitHub's 100MB file size limit and Git LFS budget limitations.

Excluded large or LFS-managed files include:

- paper_artifacts/datasets/normal/window_typing_10000.csv
- paper_artifacts/datasets/attack/AdaptiveMimic_v8_candidate/v8_candidates.csv
- paper_artifacts/datasets/attack/AdaptiveMimic_v5_constrained_test/*.csv
- paper_artifacts/datasets/attack/AdaptiveMimic_v6_D1_OR90_bypass_train/*.csv
- paper_artifacts/datasets/attack/AdaptiveMimic_v6_D1_OR90_bypass_test/*.csv
- paper_artifacts/datasets/attack/AdaptiveMimic_v7_D2_OR90_bypass_train/*.csv
- paper_artifacts/datasets/attack/AdaptiveMimic_v7_D2_OR90_bypass_test/*.csv
- paper_artifacts/datasets/attack/AdaptiveMimic_v8_D3_hardest_no_bypass/*.csv
- paper_artifacts/datasets/random_matched/*.csv

The repository keeps code, tables, figures, and notes required to reproduce the paper artifact structure.
Full datasets should be stored separately in lab storage, Google Drive, OneDrive, or Hugging Face Datasets.
